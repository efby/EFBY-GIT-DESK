# EfbyGitDesk

Aplicación nativa para macOS desarrollada en Swift, con Clean Architecture e integración inicial con Bitbucket Cloud.

Repositorio de desarrollo: [efby/EFBY-GIT-DESK](https://github.com/efby/EFBY-GIT-DESK).

La especificación cubre repositorios y ramas, commits, fetch/pull/push, historial, comparación de exactamente dos commits, edición del mensaje de HEAD publicado y terminal integrado.

Estado inicial: documentación y preparación del repositorio; la aplicación todavía no está implementada. El siguiente hito es **H0 — Viabilidad nativa**, que valida Git, PTY, Keychain y el entorno desde Finder antes de desarrollar funcionalidades.
